## Model Selection
Before executing any task I ask you to implement, write a one-line model recommendation showing:
1. Which model fits (Haiku / Sonnet 5.5 / Opus 5.5 / Fable 5.1)
2. Why (reasoning, latency, cost tradeoff)
3. Only then proceed

Example:
> **Model:** Sonnet 5.5 — coding task, speed acceptable, cost-efficient
> [then do the work]
